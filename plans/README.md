  現行の「EXAMS データ駆動 + 3 ファイル変更で新試験追加」というアーキテクチャの単純さ・
  Netlify 静的デプロイとの整合を壊すため、現段階では見送り（004 の Maintenance notes に再検討条件を記載）。
- **litellm / dspy を用いた最新情報自動収集パイプライン**: `CLAUDE.md` の制約事項で両ライブラリの追加が
  明示的に禁止されているため対象外。002 では手動チェック周期ベースの運用を設計する。
- **全試験の一括ページ実装計画**: improve スキルの原則（頼まれていない 30 本のプランを書かない）に従い、
  個別試験の実装プランは 003 の優先度表で選定されたものだけを将来の `plans/005+` として起票する。
